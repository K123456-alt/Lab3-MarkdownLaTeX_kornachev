## Сноска

Markdown полезен в разработке[^markdown].

[^markdown]: Markdown — это лёгкий язык разметки, который широко используется для оформления README-файлов, документации, отчётов и комментариев в коде.

---

## Alert-блок

> [!TIP]
> Совет по использованию: для экранирования специальных символов в Markdown используйте обратный слэш `\`. Например, чтобы написать `*курсив*` без форматирования, напишите `\*курсив\*`.
---
## Escape-символы

- Заголовок без форматирования: \# Это не заголовок
- Звёздочка как текст: \*Просто звёздочка\*
- Подчёркивание как текст: \_Просто подчёркивание\_

## HTML в Markdown

<p style="background-color: #f8f9fa; padding: 15px; border-radius: 5px; border-left: 4px solid #007bff;">
Этот параграф оформлен с помощью <strong>HTML-тега</strong> внутри Markdown-документа. HTML позволяет расширить возможности разметки, например, добавить цвет фона, отступы и границы.
</p>
